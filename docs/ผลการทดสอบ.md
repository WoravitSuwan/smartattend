อยู่ในสถานะเดียวกับโค้ด** ข้อ M-00 ถึง M-02 ใน
[รายการตรวจสอบด้วยมือ.md](./รายการตรวจสอบด้วยมือ.md) เป็นคำสั่งสั้น ๆ

| | เส้นทางที่ 1 — การฝึกแบบจำลองบนหน้าเว็บ | เส้นทางที่ 2 — การเช็คชื่อจริงที่อุปกรณ์ |
|---|---|---|
| วิธีการ | โครงข่ายประสาทเทียมแบบ closed-set softmax | เทียบเวกเตอร์ใบหน้า 128 มิติด้วยระยะยุคลิด |
| ไลบรารี | TensorFlow.js (`@tensorflow/tfjs`) | `face_recognition` ซึ่งใช้ dlib |
| ทำงานที่ไหน | เบราว์เซอร์ของผู้ดูแลระบบ | Raspberry Pi |
| ที่มาของข้อมูล | ตาราง `face_images` | ตาราง `face_images` |
| ผลลัพธ์เก็บที่ | ตาราง `face_models` + storage | สร้างคลังเวกเตอร์ในหน่วยความจำของอุปกรณ์ |
| เกณฑ์ตัดสิน | ความน่าจะเป็นจาก softmax | ระยะห่าง ≤ 0.6 (ค่ามาตรฐานของ dlib) |

**หลักฐาน** ค้นทั้งโฟลเดอร์ `smartattend_pi/` ด้วยคำว่า `face_models`,
`training_runs` และ `can_use_face_model` — **ไม่พบการอ้างถึงแม้แต่แห่งเดียว**
อุปกรณ์ดึงภาพจาก `face_images` มาสร้างเวกเตอร์เองทุกครั้ง
(`pi_agent.py:125` → `supabase_client.py:108` → `face_recognizer.py:82`)
ส่วนไฟล์แบบจำลองที่ฝึกไว้ไม่เคยถูกดาวน์โหลดไปที่อุปกรณ์

ความเห็นนี้ตรงกับหมายเหตุที่เขียนไว้ในโค้ดเองที่
`smartattend_web/src/lib/real-trainer.ts` บรรทัดที่ 17

### สิ่งที่เขียนได้และเขียนไม่ได้ในเล่มปริญญานิพนธ์

| เขียนได้ | เขียนไม่ได้ |
|---|---|
| "ระบบเช็คชื่อด้วยการเทียบเวกเตอร์ใบหน้า 128 มิติจาก dlib โดยใช้เกณฑ์ระยะห่าง 0.6" | "ระบบใช้แบบจำลองที่ฝึกขึ้นเองในการเช็คชื่อ" |
| "ระบบมีส่วนฝึกแบบจำลอง CNN เพื่อประเมินคุณภาพชุดข้อมูลใบหน้าที่เก็บมา" | "ค่าความถูกต้องของแบบจำลองคือความแม่นยำของการเช็คชื่อ" |
| "ค่าความถูกต้องที่รายงานคือผลของแบบจำลอง CNN บนชุดข้อมูลที่เก็บไว้" | "แบบจำลองถูกนำไปใช้งานบนอุปกรณ์ประจำห้องเรียน" |

**ข้อเสนอ** ถ้าต้องการให้เล่มสอดคล้องกับระบบจริง ควรเลือกทางใดทางหนึ่ง
(1) อธิบายส่วนฝึกแบบจำลองว่าเป็นเครื่องมือประเมินคุณภาพชุดข้อมูล ไม่ใช่กลไกเช็คชื่อ หรือ
(2) วัดความแม่นยำของการเช็คชื่อจริงด้วยการทดสอบ H-01 แล้วรายงานตัวเลขนั้นแทน
ทางที่ (1) ไม่ต้องแก้โค้ดเลย
