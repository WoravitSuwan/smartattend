# SmartAttend — ระบบตรวจสอบการเข้าเรียนอัตโนมัติด้วยการจดจำใบหน้า

ปริญญานิพนธ์ หลักสูตรวิศวกรรมซอฟต์แวร์ คณะวิศวกรรมศาสตร์
มหาวิทยาลัยเทคโนโลยีราชมงคลล้านนา เชียงใหม่

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| ส่วนติดต่อผู้ใช้ | React 18 + TypeScript + Vite |
| การจัดรูปแบบ | Tailwind CSS + shadcn/ui |
| ฐานข้อมูลและระบบหลังบ้าน | Supabase (PostgreSQL) |
| การจดจำใบหน้า (เว็บ) | TensorFlow.js |
| การจดจำใบหน้า (อุปกรณ์) | Python + dlib บน Raspberry Pi |

## เริ่มต้นใช้งาน

```bash
npm install
cp .env.example .env    # แล้วแก้ค่าให้ตรงกับโปรเจกต์ของคุณ
npm run dev
```

เปิด http://localhost:8080

หรือกด **F5 ใน VS Code** เลือก `▶ รันเว็บ + เปิดเบราว์เซอร์`

## คำสั่งที่ใช้บ่อย

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | รันโหมดพัฒนา แก้โค้ดแล้วเห็นผลทันที |
| `npm run build` | สร้างไฟล์สำหรับใช้งานจริงในโฟลเดอร์ `dist/` |
| `npm run preview` | ทดสอบผลลัพธ์ของ build ก่อน deploy |
| `npm run lint` | ตรวจสอบคุณภาพโค้ด |

## การตั้งค่าฐานข้อมูล

ไฟล์ migration ทั้งหมดอยู่ใน `supabase/migrations/` เรียงตามลำดับเวลา
หากต้องการสร้างฐานข้อมูลใหม่ตั้งแต่ต้น:

```bash
npx supabase link --project-ref <รหัสโปรเจกต์ของคุณ>
npx supabase db push
```

## ติดตั้งเป็นแอปมือถือ

โปรเจกต์นี้รองรับ PWA เมื่อ deploy แล้วผู้ใช้สามารถกด "ติดตั้งเป็นแอป"
จากเบราว์เซอร์ได้ทั้งบน Android และ iOS โดยไม่ต้องผ่าน App Store

ดูรายละเอียดเพิ่มเติมที่ `../SETUP.md`

## โปรแกรมบน Raspberry Pi

โค้ดส่วนที่ทำงานร่วมกับกล้องและอุปกรณ์อยู่ในโฟลเดอร์ `../smartattend_pi/`
เขียนด้วย Python ทั้งหมด
