## การจดจำใบหน้าในระบบนี้ทำงานอย่างไร (อ่านก่อนเขียนเอกสาร)

ระบบมีงานที่เกี่ยวกับใบหน้า **สองส่วนที่ใช้วิธีต่างกันโดยสิ้นเชิง** และไม่ได้ต่อกัน
ถ้าเขียนเอกสารหรืออธิบายระบบ ต้องแยกสองส่วนนี้ให้ชัด

### ส่วนที่ใช้เช็คชื่อจริง — dlib embedding บน Raspberry Pi

`smartattend_pi/face_recognizer.py`

1. `face_recognition` (dlib) หาตำแหน่งใบหน้าในเฟรมจากกล้อง USB
2. แปลงใบหน้าเป็น **เวกเตอร์ 128 มิติ (embedding)**
3. วัดระยะห่างกับเวกเตอร์ของนักศึกษาในวิชานั้น ถ้าใกล้กว่าเกณฑ์ถือว่าเป็นคนนั้น
4. ส่งผลขึ้น RPC `record_attendance()` ซึ่งเป็นฝ่ายตัดสินว่า **ตรงเวลาหรือมาสาย**
   ด้วยเวลาของเซิร์ฟเวอร์ (อุปกรณ์ไม่คำนวณเวลาเอง — ดู SECURITY.md ข้อ 1.3)

วิธีนี้เพิ่มนักศึกษาใหม่ได้โดยไม่ต้องเทรนอะไรใหม่ (แค่เพิ่มเวกเตอร์)
และปฏิเสธคนแปลกหน้าได้เมื่อระยะห่างเกินเกณฑ์

### ส่วนที่เป็นการทดลอง — CNN บนเบราว์เซอร์ (ยังไม่ถูกนำไปใช้เช็คชื่อ)

`smartattend_web/src/lib/real-trainer.ts` + `face-model-store.ts`
หน้าจอ: เทรนโมเดล / ประวัติการเทรน / กราฟผลการเทรน (ทุกหน้าติดป้าย "ทดลอง")

เทรน CNN ขนาดเล็กด้วย **TensorFlow.js ในเบราว์เซอร์** จากภาพลงทะเบียนใบหน้า
(Conv → Pool → Conv → Pool → Dense → Softmax) แล้วอัปโหลดโมเดลขึ้น bucket `face-models`

> **ไม่มีส่วนใดของระบบเรียกโมเดลนี้มาจดจำใบหน้า**
> ตรวจแล้วไม่มีโค้ดใดใน `smartattend_pi/` โหลดโมเดลนี้ และไม่มีหน้าของนักศึกษา
> หรืออาจารย์ที่ใช้ผลทำนายจากโมเดลนี้ตัดสินอะไร
>
> ตัวเลขความแม่นยำ (accuracy / loss / val acc) บนหน้าเทรน **เป็นตัวเลขจริงของ
> การเทรนจริง** แต่เป็นความแม่นยำของ closed-set classification บนชุดข้อมูลที่
> ลงทะเบียนไว้ ไม่ใช่ความแม่นยำของการเช็คชื่อหน้าห้องเรียน
>
> **ห้ามเขียนในปริญญานิพนธ์หรือเอกสารใด ๆ ว่าระบบใช้ CNN จดจำใบหน้าเพื่อเช็คชื่อ**
> เพราะโค้ดไม่ได้ทำเช่นนั้น ถ้าจะกล่าวถึงส่วนนี้ ให้กล่าวตามจริงว่าเป็นการทดลอง
> ฝึกแบบจำลองเปรียบเทียบ ซึ่งยังไม่ถูกนำไปใช้ในเส้นทางการเช็คชื่อ

เหตุผลที่ทั้งสองส่วนไม่ต่อกัน: closed-set softmax ต้องเทรนใหม่ทุกครั้งที่มีนักศึกษา
เพิ่ม และบังคับให้ผลรวมความน่าจะเป็นเท่ากับ 1 เสมอ จึงตอบ "ไม่ใช่ใครในระบบ" ไม่ได้
ซึ่งเป็นคุณสมบัติที่จำเป็นสำหรับการเช็คชื่อหน้าห้องเรียน

### ถ้าจะทำให้ส่วนทดลองมีที่ใช้จริงในอนาคต

**อย่า** วัดคุณภาพภาพด้วยการให้โมเดลทำนายภาพของเจ้าของเองหลังเทรนเสร็จ
ภาพนั้นอยู่ในชุดเทรนแล้ว ความมั่นใจจะสูงเสมอโดยไม่ได้บอกคุณภาพอะไร (data leakage)

แนวทางที่วัดได้จริงมีสองทาง

1. **ตรวจคุณภาพภาพก่อนเทรน** ด้วย BlazeFace ที่มีอยู่แล้วใน `src/lib/face-crop.ts`
   — เจอใบหน้าเดียว ขนาดไม่เล็กเกินไป ไม่เบลอ ไม่มืดหรือย้อนแสง
   ถ้าไม่ผ่านให้แจ้งนักศึกษาถ่ายใหม่ทันทีตอนอัปโหลด
2. **ตรวจการสลับตัวบุคคล** โดยเอาภาพใหม่ไปทำนายกับโมเดล *รอบก่อน* ก่อนเทรนรอบใหม่
   ถ้าถูกทำนายเป็นคนอื่นด้วยความมั่นใจสูง ให้เตือนว่าอาจส่งภาพผิดคน
